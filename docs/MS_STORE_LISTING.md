## Store listing – English (en-us)

**Product name:** KeyFlip

**Short description (≤ 270 chars – used for Windows/Xbox in some views):**
Typed `akuo` instead of `שלום`, or `ghbdtn` instead of `привет`? KeyFlip fixes words typed in the wrong keyboard layout – Hebrew, Russian, Arabic ↔ English, French, German, Spanish – right after you press Space. Everything runs locally.

**Description:**
KeyFlip fixes text typed in the wrong keyboard layout: Hebrew, Russian or Arabic ↔ English, French, German or Spanish.

Forgot to switch the language and typed `akuo jcrho`? KeyFlip turns it into `שלום חברים` as soon as you finish the word. Typed `יקךךם` instead of `hello`? Fixed too.

LANGUAGES
• Hebrew ↔ English: always on.
• Russian ↔ English (`ghbdtn` → привет) and Arabic ↔ English (`Hkh` → أنا): turned on automatically when the Russian or Arabic keyboard is installed in Windows.
• French, German and Spanish, including AZERTY, QWERTZ and Spanish keyboards: turned on automatically when such a keyboard is installed. Choose languages and your Latin keyboard in the tray menu.
• Optional: switch the keyboard language automatically after a fix, so the next words come out right.
• Short words in a sentence (`kt tck` → לא אבל) and words missing from the dictionary are recognised too.

HOW IT WORKS
• Automatic: after each word (Space), KeyFlip checks whether it was typed in the wrong layout and fixes it.
• Undo: press Ctrl+Alt+Space right after a fix to restore what you typed.
• Manual: select text and press Ctrl+Alt+Space to convert it, or press it after typing to convert the last words on the line.
• Runs quietly in the notification area (next to the clock). Right-click the icon for settings.

PRIVACY FIRST
• Everything runs on your computer. No network access, no analytics, no accounts, no ads.
• Only the current line (up to 200 characters) is kept in memory – never written to disk or logs.
• Nothing is tracked at all in password managers, terminals, remote-desktop tools and code editors, or while a password field has focus.
• Browsers are skipped by default (the free KeyFlip Chrome extension handles them) and can be enabled from the tray menu.

GOOD TO KNOW
• Does not work in windows running as administrator.
• Detection combines word lists with a statistical model; very rare words may occasionally be skipped or corrected wrongly – undo is one shortcut away.
• Open source (Apache-2.0): https://github.com/diamondrubinny/keyflip

**What's new in this version (0.3.0):**
New languages: French, German and Spanish, with support for AZERTY, QWERTZ and Spanish keyboards (accents and dead keys included). New tray menu "Languages & keyboard" to choose languages and your Latin keyboard, and an optional automatic keyboard switch after a fix. Russian one-letter words (у, в, с) are fixed too.

1. Automatically fixes words typed in the wrong keyboard layout: Hebrew, Russian, Arabic ↔ English, French, German, Spanish
2. Undo any fix instantly with Ctrl+Alt+Space
3. Convert selected text or the last typed words with one shortcut
4. 100% local – no internet, no analytics, no account
5. Never tracks password fields, password managers, terminals or code editors
6. Option to start with Windows; lightweight tray app
7. Free and open source

Набрали `ghbdtn` вместо «привет»? KeyFlip исправляет слова, набранные не в той раскладке – русский, иврит, арабский ↔ английский, французский, немецкий, испанский – сразу после пробела. Всё работает локально, данные не покидают компьютер.

**Описание:**
KeyFlip исправляет текст, набранный не в той раскладке клавиатуры: русский, иврит или арабский ↔ английский, французский, немецкий или испанский.

Забыли переключить язык и набрали `ghbdtn rfr ltkf`? KeyFlip превратит это в «привет как дела», как только вы закончите слово. Набрали `руддщ` вместо `hello`? Тоже исправится.

ЯЗЫКИ
• Русский ↔ английский: включается автоматически, если в Windows установлена русская раскладка.
• Иврит ↔ английский: всегда включён.
• Арабский ↔ английский: включается автоматически, если установлена арабская раскладка.
• Французский, немецкий и испанский, включая клавиатуры AZERTY, QWERTZ и испанскую: включаются автоматически, если такая раскладка установлена. Языки и латинская клавиатура выбираются в меню программы.
• По желанию: автоматическое переключение языка клавиатуры после исправления, чтобы следующие слова набирались правильно.
• Распознаются и короткие слова в предложении, и слова, которых нет в словаре.

КАК ЭТО РАБОТАЕТ
• Автоматически: после каждого слова (пробел) KeyFlip проверяет, не набрано ли оно в неправильной раскладке, и исправляет его.
• Отмена: нажмите Ctrl+Alt+Space сразу после исправления, чтобы вернуть набранное.
• Вручную: выделите текст и нажмите Ctrl+Alt+Space или нажмите эти клавиши после набора, чтобы преобразовать последние слова в строке.
• Работает незаметно в области уведомлений (рядом с часами). Настройки – правой кнопкой мыши по значку. Меню программы на иврите.

ПРИВАТНОСТЬ
• Всё работает на вашем компьютере: без интернета, аналитики, учётной записи и рекламы.
• В памяти хранится только текущая строка (до 200 символов); ничего не записывается на диск или в журналы.
• В менеджерах паролей, терминалах, программах удалённого доступа, редакторах кода и в полях пароля ничего не отслеживается.
• В браузерах по умолчанию отключено (там работает бесплатное расширение KeyFlip для Chrome); можно включить в меню.

ПОЛЕЗНО ЗНАТЬ
• Не работает в окнах, запущенных от имени администратора.
• Распознавание сочетает словари и статистическую модель; очень редкие слова иногда могут быть пропущены или исправлены неверно – отмена в одно нажатие.

## Submission options → Notes for certification
```
KeyFlip is a tray (notification area) app with no main window. After launch, a balloon explains that it is running next to the clock; right-click the tray icon (it may be under the ^ overflow arrow) for the menu.

How to test:
1. Add the Hebrew keyboard (Settings > Time & language > Language & region > Add a language > Hebrew) but keep the English layout active.
2. Open Notepad and type: akuo jcrho  then press Space -> it becomes: שלום חברים
3. Switch to the Hebrew layout and type the keys for "hello" (יקךךם) then Space -> it becomes: hello
4. Press Ctrl+Alt+Space right after a fix -> the fix is undone.
5. Select any text and press Ctrl+Alt+Space -> it is converted.
Tray menu: auto-correct on/off, also work in browsers, convert now, languages & keyboard (Russian, Arabic, French, German, Spanish; Latin keyboard: US/AZERTY/QWERTZ/Spanish), switch keyboard language after a fix (off by default), start with Windows, privacy & info, exit.

Privacy: a low-level keyboard hook is used only to detect word boundaries. Only the current line (max. 200 chars) is kept in memory; nothing is written to disk, logged or sent over the network (the app makes no network requests). It does nothing in password managers, terminals, remote tools, code editors and password fields. Privacy policy: https://github.com/diamondrubinny/keyflip/blob/main/docs/PRIVACY.md
No account, login or test credentials are required. Source code: https://github.com/diamondrubinny/keyflip
```

## Restricted capability justification – `runFullTrust`
```
KeyFlip is a Win32 (.NET 10 WinForms) desktop tray app packaged as MSIX. It needs runFullTrust because it uses a low-level keyboard hook (SetWindowsHookEx WH_KEYBOARD_LL) to detect when a word is finished, SendInput to replace a word typed in the wrong keyboard layout, RegisterHotKey for the Ctrl+Alt+Space shortcut, and the clipboard to convert selected text. These Win32 APIs are not available to partial-trust apps. All processing is local; the app makes no network requests.
```
