# Code of Conduct

KeyFlip follows the spirit of the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Our standards
- Be respectful and welcoming to everyone, regardless of background, identity, language or experience level.
- Give and accept constructive feedback; focus on what is best for the users and the project.
- No harassment, insults, sexualised language, personal attacks, or publishing others' private information.
- Never use KeyFlip, its issues or its code to monitor other people's typing without their knowledge.

## Enforcement
The maintainer may edit or remove comments, commits and issues that break these standards and may block contributors who repeatedly do so.
Report problems privately via [a private security advisory](https://github.com/diamondrubinny/keyflip/security/advisories/new) (choose "Code of conduct" in the title) or by contacting the maintainer on GitHub ([@diamondrubinny](https://github.com/diamondrubinny)). Reports are handled confidentially.
